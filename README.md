# Wunder Web Studio — GitHub Pages

Site estático de Kauê Ribeiro / Wunder Web Studio.

## Publicação

1. Crie um repositório chamado `Wunder-WebStudio.github.io`.
2. Envie `index.html` e a pasta `assets` para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.

O site usa apenas HTML, CSS e JavaScript e funciona diretamente no GitHub Pages.
