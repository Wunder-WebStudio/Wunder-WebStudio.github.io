# Wunder Web Studio — GitHub Pages

Site estático pronto para publicação no GitHub Pages.

## Estrutura

- `index.html` — página principal, estilos e interações.
- `assets/wunder-logo.png` — logo.
- `assets/wunder-bg.png` — textura/fundo do visual.

## Publicação no GitHub Pages

Crie um repositório público no GitHub e envie os arquivos mantendo a estrutura de pastas. Depois, em **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch principal e a pasta **/(root)**.

O site não precisa de Node, build ou servidor: é HTML/CSS/JS puro.
